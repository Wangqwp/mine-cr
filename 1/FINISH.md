🚀 使用方式
════════════════════════════════════════════════════════════════════

【方式 1】菜单模式 (推荐)
  
  $ pip install requests
  $ python main.py
  
  然后选择:
    1 - 单次爬取
    2 - 每分钟更新
    3 - 自定义间隔

【方式 2】直接运行

  $ python stock_crawler_v2.py

【方式 3】代码方式

  from stock_crawler_v2 import StockCrawler
  
  crawler = StockCrawler()
  crawler.run_once()  # 单次爬取
  # 或
  crawler.run_continuous(60)  # 每分钟更新
