步骤 1: 安装依赖
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  Windows:
    pip install requests

  Linux/Mac:
    pip3 install requests

⏱️  耗时约 10-30 秒


步骤 2: 运行爬虫
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  选项 A: 使用菜单（推荐）
    python main.py
    
    然后选择:
    1 - 单次爬取
    2 - 每分钟更新
    3 - 自定义间隔

  选项 B: 直接运行
    python stock_crawler_v2.py

  选项 C: 自定义脚本
    python -c "from stock_crawler_v2 import StockCrawler; StockCrawler().run_once()"

⏱️  耗时约 1-3 秒


步骤 3: 查看数据
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  数据自动保存到:
    📂 stock_data/
      └─ latest.json (最新数据)
      └─ stock_data_*.json (历史数据)

  查看数据:
    Windows: type stock_data\latest.json
    Linux/Mac: cat stock_data/latest.json

✅ 完成！

📝 添加自己的股票

  编辑: stock_crawler_v2.py
  
  找到 get_hot_stocks() 方法，修改列表:
  
    def get_hot_stocks(self) -> List[str]:
        return [
            'sh000001',  # 上证指数
            'sh600000',  # 浦发银行
            'sh601398',  # 工商银行 (添加)
            'sz000333',  # 美的集团 (添加)
        ]

📂 修改数据保存位置

  crawler = StockCrawler(data_dir='./my_data')

⏱️ 修改更新间隔

  crawler.run_continuous(interval=20)  # 每20秒更新

❌ 无法获取数据

  解决步骤:
  
  1. 检查网络
     ping baidu.com
  
  2. 测试数据源
     python simple_test.py
  
  3. 查看日志
     type stock_crawler.log
  
  4. 确认交易时间
     周一-周五 09:30-15:00 (中国时间)

❌ 爬虫运行缓慢

  解决方案:
  
  • 检查网络速度
  • 减少股票数量
  • 增加更新间隔

❌ 报错 "ModuleNotFoundError"

  解决方案:
  
  pip install -r requirements.txt
  # 或
  pip install requests
