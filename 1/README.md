# 中国股市实时爬虫

这是一个强大的、可产用级的中国A股股市数据爬虫，能够实时获取股票行情数据。

## 📦 新版本 v2.0 更新

✨ **核心改进**
- 支持多数据源（东方财富 + 新浪财经）
- 自动数据源切换和补充
- 数据获取更加稳定可靠
- 优化了数据解析逻辑
- 增强的错误恢复机制

## 功能特性

✨ **核心功能**
- 实时爬取中国A股股票数据（沪深两市）
- 自动获取主要指数（上证指数、深证成指、创业板指）
- 爬取热门股票的详细信息
- 灵活的更新频率控制（支持自定义间隔）
- JSON 格式数据存储
- 支持多数据源自动切换

📊 **数据指标**
每只股票包含以下实时数据：
- 股票代码、名称
- 当前价格、最高价、最低价、开盘价、昨收价
- 涨跌幅（绝对值和百分比）
- 成交量、成交额

🔧 **特点**
- 多数据源支持，自动降级和补充
- 日志记录完整的爬取过程
- 错误自动恢复机制
- 最新数据实时覆盖保存
- 历史数据按时间戳保存
- 友好的命令行交互界面
- 完全兼容旧版本

## 安装

### 1. 安装依赖
```bash
pip install -r requirements.txt
```

### 2. 运行爬虫

#### 方式一：使用交互式菜单
```bash
python main.py
```

选择选项：
- `1` - 单次爬取
- `2` - 每分钟更新
- `3` - 自定义频率

#### 方式二：直接运行爬虫脚本

**单次爬取：**
```python
from stock_crawler_v2 import StockCrawler

crawler = StockCrawler()
crawler.run_once()
```

**连续爬取（每分钟）：**
```python
from stock_crawler_v2 import StockCrawler

crawler = StockCrawler()
crawler.run_continuous(interval=60)
```

## 注意事项

⚠️ **重要提示**

1. **网络要求**
   - 需要良好的网络连接
   - 建议在 VPS 或云服务器上运行以获得稳定性

2. **交易时间**
   - A股交易时间：周一至周五 9:30-15:00（中国标准时间）
   - 非交易时间获取的数据为最后收盘价格

3. **更新频率**
   - 建议更新间隔不低于 10 秒
   - 过于频繁的请求可能会被限流

4. **数据准确性**
   - 数据来自第三方数据源
   - 用于学习和参考，不作为投资建议依据

## 常见问题

**Q: 爬虫连接失败怎么办？**
A: 
- 检查网络连接
- 运行 `simple_test.py` 测试数据源可用性
- 查看 `stock_crawler.log` 日志文件

**Q: 数据为空？**
A:
- 新版本会自动在两个数据源间切换
- 确保网络连接正常
- 运行 `simple_test.py` 验证数据源

**Q: 怎样获取更多股票数据？**
A: 修改 `stock_crawler_v2.py` 中的 `get_hot_stocks()` 方法，添加更多股票代码。

**Q: 能否将数据存储到数据库？**
A: 可以修改 `save_data()` 方法增加数据库支持（SQLite、MySQL等）。
